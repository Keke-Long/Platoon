\section{Problem Formulation}
\label{sec:formulation}

\subsection{Vehicles, release times, and passing sequences}

Let \(\approaches=\{1,\ldots,L\}\) denote the set of mutually conflicting approaches. Approach \(l\) contains \(n_l\) vehicles indexed in FIFO order by \((l,i)\), where \(i=1,\ldots,n_l\). The total number of vehicles is
\begin{equation}
N=\sum_{l\in\approaches}n_l.
\end{equation}
Let \(r_{l,i}\) denote the earliest time at which vehicle \((l,i)\) can enter the conflict area. Release times are assumed to respect the physical queue order:
\begin{equation}
r_{l,i}\le r_{l,i+1}.
\end{equation}

A feasible passing sequence \(s=(s_1,\ldots,s_N)\) is an interleaving of the approach queues that preserves FIFO order within every approach. Let \(\seqset\) denote the set of all such sequences. This FIFO restriction is part of the definition of \(\seqset\), rather than an implicit modeling assumption.

For two consecutively scheduled vehicles \(u\) and \(v\), define the required separation
\begin{equation}
h(u,v)=
\begin{cases}
\hF, & l_u=l_v,\\
\hS, & l_u\ne l_v,
\end{cases}
\qquad 0<\hF<\hS.
\end{equation}
For a given sequence \(s\), the earliest feasible passing times are
\begin{align}
C_{s_1}(s)&=r_{s_1},\\
C_{s_k}(s)&=\max\left\{r_{s_k},C_{s_{k-1}}(s)+h(s_{k-1},s_k)\right\},
\quad k=2,\ldots,N.
\label{eq:completion-recursion}
\end{align}
Equation~\eqref{eq:completion-recursion} uses the actual passing time of the preceding vehicle. Replacing it with the preceding release time would prevent queueing delay from propagating and would define a different problem.

The average vehicle delay is
\begin{equation}
D(s)=\frac{1}{N}\sum_{v\in\vehicles}\left(C_v(s)-r_v\right).
\end{equation}
The vehicle-level optimum is
\begin{equation}
D^*=\min_{s\in\seqset}D(s).
\end{equation}

\subsection{Contiguous platoon partitions}

A platoon partition \(\partitionP\) divides the FIFO queue of each approach into contiguous blocks. Let \(K_l\) denote the number of platoons on approach \(l\), and let
\begin{equation}
K=\sum_{l\in\approaches}K_l
\end{equation}
be the total number of scheduling units after aggregation.

Let \(\pseqset\subseteq\seqset\) denote the sequences in which all vehicles belonging to the same platoon appear consecutively. The platoon-constrained optimum and its optimality gap are
\begin{align}
D^*_{\Pi}&=\min_{s\in\pseqset}D(s),\\
G(\Pi)&=D^*_{\Pi}-D^*.
\end{align}
Since \(\pseqset\subseteq\seqset\),
\begin{equation}
G(\Pi)\ge 0.
\end{equation}

Let \(\mathcal{E}_{\Pi}\) be the set of internal links between consecutive vehicles in the same platoon. If there are \(K\) platoons, then
\begin{equation}
|\mathcal{E}_{\Pi}|=N-K.
\end{equation}
For each internal link \(e=(a,a')\), define the release-time gap
\begin{equation}
d_e=r_{a'}-r_a.
\end{equation}
