\section{Rule-Based Dimension Reduction}
\label{sec:dimension-reduction}

The loss bound in Section~\ref{sec:theory} is used as a design principle for a deterministic platooning rule. The proposed method is a preprocessing step: it constructs platoons before the downstream scheduling MILP is built, and the reduced scheduling problem is then solved by the same off-the-shelf optimizer used for the vehicle-level model. No optimization model is solved to select the platoon partition.

\subsection{Scheduling Dimension}
\label{sec:scheduling-dimension}

In the vehicle-level formulation, one binary precedence variable is introduced for each pair of vehicles from different approaches. If approach \(l\) contains \(n_l\) vehicles, the corresponding pairwise ordering dimension is
\begin{equation}
C_0=\sum_{l<l'} n_l n_{l'}.
\end{equation}
After platooning, let \(K_l(\Pi)\) denote the number of platoons on approach \(l\) under partition \(\Pi\). The platoon-level ordering dimension becomes
\begin{equation}
C(\Pi)=\sum_{l<l'} K_l(\Pi)K_{l'}(\Pi).
\label{eq:dimension-measure}
\end{equation}
This quantity measures the number of cross-approach ordering decisions in the downstream MILP. It is a deterministic model-size metric; actual branch-and-bound time is evaluated empirically and is not assumed to be a monotone function of \(C(\Pi)\).

\subsection{No Platooning and Critical-Headway Platooning}
\label{sec:np-chp-rules}

The experiments compare three preprocessing choices. The no-platooning baseline (NP) leaves every vehicle as a singleton platoon, so \(K_l=n_l\) and \(C(\Pi)=C_0\). Conventional critical-headway platooning (CHP) scans vehicles on each approach in FIFO order and joins two consecutive vehicles into the same platoon whenever their release-time gap is no greater than a threshold \(\delta\). CHP uses no maximum platoon-size cap; once a platoon has started, consecutive same-approach vehicles continue to join as long as each adjacent release gap satisfies the threshold rule.

The switching headway \(\hS\) is not a platooning threshold. It is the safety headway required when the scheduled sequence switches from one approach to another. The platooning threshold is \(\delta\), which is applied only to release-time gaps between consecutive vehicles on the same approach.

\subsection{Proposed Threshold-and-Cap Platooning}
\label{sec:pp-rule}

The proposed method (PP) modifies CHP by adding a maximum platoon size \(P_{\max}\). For each approach \(l\), vehicles are processed in their FIFO order. A new platoon is opened at the first unassigned vehicle. For each next vehicle on the same approach, PP joins it to the current platoon if and only if both conditions hold:
\begin{align}
r_{l,i+1}-r_{l,i} &\le \delta,\\
\text{current platoon size} &< P_{\max}.
\end{align}
If either condition fails, the current platoon is closed and a new platoon starts at vehicle \((l,i+1)\). The resulting partition is contiguous within each approach and never mixes vehicles from different approaches.

Equivalently, the PP construction can be written as the following one-pass procedure.
\begin{enumerate}[label=\arabic*.]
  \item For each approach, initialize the current platoon with the first vehicle.
  \item Scan the remaining vehicles on that approach in increasing FIFO index.
  \item Add the next vehicle to the current platoon if its release gap from the preceding vehicle is at most \(\delta\) and the current platoon contains fewer than \(P_{\max}\) vehicles.
  \item Otherwise, close the current platoon and start a new singleton platoon.
  \item Repeat until all approaches have been scanned.
\end{enumerate}
The procedure is deterministic for fixed arrivals, \(\delta\), and \(P_{\max}\). It requires only adjacent release-gap comparisons and platoon-size counters.

\subsection{Rule-Level Loss Bound}
\label{sec:rule-level-bound}

For a specific platoon partition \(\Pi\), Section~\ref{sec:theory} gives a FIFO-indexed upper bound on the platooning-induced average-delay gap \(G(\Pi)\). PP uses a rule-level bound that depends only on the instance size and the two rule parameters \(\delta\) and \(P_{\max}\). Let
\begin{equation}
M_{\max}=N-\left\lceil\frac{N}{P_{\max}}\right\rceil
\end{equation}
be an upper bound on the number of internal same-approach links that can be created under the size cap. Since PP joins only adjacent vehicles whose release-time gap is at most \(\delta\), each internal link is bounded by the worst-case rule-level contribution derived in Section~\ref{sec:theory}. The implemented rule-level upper bound is
\begin{equation}
\widehat G(\delta,P_{\max})
=
M_{\max}
\left[
\frac{N-1}{N}\pospart{\delta-\hF}
-\frac{2(\hS-\hF)}{N}
\right]_+ .
\label{eq:rule-level-bound-method}
\end{equation}
Thus, for partitions generated by PP,
\begin{equation}
G(\Pi_{\mathrm{PP}})\le \widehat G(\delta,P_{\max}).
\end{equation}
Increasing \(\delta\) can join more vehicles and increase the bound through the release-gap term. Increasing \(P_{\max}\) can also increase the bound by allowing more internal links. These two parameters therefore control the trade-off between model-size reduction and the worst-case delay-loss guarantee.

\subsection{Downstream Scheduling Model}
\label{sec:downstream-after-pp}

After NP, CHP, or PP constructs a partition, the downstream platoon-level scheduling MILP from Section~\ref{sec:formulation} is built on the resulting scheduling units. Vehicles inside a platoon preserve FIFO order and pass consecutively. The MILP chooses the relative order of platoons from different approaches and their passing times subject to the same following and switching headway requirements. The preprocessing rule does not change the downstream solver; it changes only the number and composition of scheduling units.

For PP, the reported preprocessing time is the time needed to form platoons by the deterministic scan. The end-to-end computational comparison therefore consists of rule-based formation time plus downstream scheduling time, with the downstream MILP solved under the common time limit used in the experiments.

\subsection{Computational Complexity}
\label{sec:pp-complexity}

Let \(N=\sum_l n_l\). NP creates singleton platoons in \(O(N)\) time. CHP and PP each compare only adjacent vehicles on the same approach, so they also run in \(O(N)\) time and require \(O(N)\) storage for the resulting partition. The size cap in PP adds only a constant-time counter update at each vehicle. Consequently, the proposed preprocessing step is negligible relative to the downstream mixed-integer scheduling solve, while it can substantially reduce the number of ordering variables from \(C_0\) to \(C(\Pi_{\mathrm{PP}})\).
